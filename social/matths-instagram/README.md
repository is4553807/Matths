# Matths 인스타그램 고정 피드 카드뉴스

## 결과물

- 규격: `1080 × 1440 px` 고해상도 PNG
- 구성: Feed 1은 5장, Feed 2·3은 각 6장, 총 17장
- 첫 장: 3개를 나란히 놓으면 이어지는 파노라마 커버
- 카드 내 캐러셀 페이지 숫자: 표시하지 않음
- 전체 카드 배경: Matths 딥블루 계열로 통일
- 실제 서비스 기능 화면: 통합·학교 게시판, 40초 눈풀이, 아카이브,
  주간 모의고사, 오답노트, War of GOAT
- 데모 계정 가명: `하준`

## 피드 구성

### Feed 1 — Community Playground

1. 이어지는 커버: `수학앱인데,`
2. 통합 고등학교 게시판과 학교별 게시판
3. 급식 줄에서 한 판 하는 `40초 눈풀이`
4. 스트레스 문구가 나중에 동기부여로 돌아오는 흐름
5. 랭킹 코인을 기프티콘으로 바꾸는 `GOAT SHOP`

추천 캡션:

> 전체 게시판과 학교 게시판, 급식 줄에서 할 수 있는 40초 눈풀이,
> 오답 리벤지와 랭킹 코인 상점을 한곳에 모았습니다.

### Feed 2 — Exam Replay

1. 이어지는 Matths 로고 커버
2. 매주 새로 공개되는 사설 모의고사
3. 최근 5개년·학교별 기출·주간 모의고사 아카이브
4. 풀었던 모의고사의 풀이과정 리플레이
5. 오답에서 비슷한 유형으로 바로 재도전
6. 모의고사 → 풀이과정 → 유사 유형 문제의 콘텐츠 흐름

추천 캡션:

> 매주 새 모의고사가 공개됩니다. 과거 기출은 한곳에 모으고,
> 풀었던 문제는 풀이과정과 비슷한 유형 문제로 다시 연결합니다.

### Feed 3 — War of GOAT

1. 이어지는 커버: `왜 재밌지?`
2. 배치 결과 `실버 2`
3. 전체 `483위`·학교 내 `12위`
4. 일요일 1타임 15:00–16:40 · 2타임 18:00–19:40 ·
   3타임 21:00–22:40
5. 100위가 1위를 지목하는 랭킹 스위칭과 방어 보상
6. 다음 일요일 랭킹 재도전

추천 캡션:

> 일요일 랭킹전에서 순위를 확인합니다. 100위도 1위를 지목할 수 있고,
> 도전자가 이기면 순위가 즉시 바뀝니다. 1위가 막아내면 방어 코인을 받습니다.

공통 해시태그:

`#Matths #고등학생 #고딩 #수학스타그램 #모의고사 #오답노트 #학교생활 #공부앱 #실수들의전쟁 #40초눈풀이`

## 업로드 순서

프로필 상단에서 왼쪽부터 `Feed 1 → Feed 2 → Feed 3`으로 보이게 하려면
새 게시물을 `Feed 3 → Feed 2 → Feed 1` 순서로 게시한 뒤 고정합니다.
각 폴더에서는 파일명 순서대로 이미지를 선택합니다.

## 디자인 원칙

- 큰 카피는 카드당 1~2문장
- 실제 서비스 화면에서 내비게이션과 미완성 하단을 제거하고
  보여줄 기능 영역만 정확히 크롭
- 로고·한글·UI 문구는 생성 이미지가 아니라 직접 조판
- 페이지 번호와 불필요한 규칙 설명 제거
- 개념 설명보다 커뮤니티·게임·경쟁·리벤지 경험 강조
- 노란색 강조를 제거하고 블루·바이올렛·코랄·시안만 사용
- 전체 텍스트는 Paperlogy 9종 굵기로 통일해 기하학적이면서도
  덜 딱딱한 디스플레이 타이포그래피로 구성
- 경쟁 결과를 상징하는 마지막 왕관 오브젝트는 원본 골드 컬러 유지
- 욕설은 특정 학생을 공격하지 않고 본인의 수학 스트레스를 표현하는
  문장으로만 사용
